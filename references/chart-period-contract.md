# 图表最新期与期间口径契约

修订日期：2026-10-25。适用于所有研究批次，不把“2026”写死在脚本中。

## 数据流与交付物

1. B3.6：`research_pipeline.py`（包括 audit-only）调用 `chart_periods.refresh_period_pack`，从三表CSV识别最新实际报告期，生成 `reports/图表最新期数据.json`。
2. 构图：`analyze_charts.py` 每次重新读取原始三表并更新证据包；图01、02、04、05、12、15在原图按年份分组，每年为完整年度空心柱和Q1—Q4季度蓝柱。未完年度不画全年柱，尚未披露季度留空；禁止在右边另画面板代替整合。PNG与Plotly均包含最新实际值。
3. `reports/图表期间覆盖.json` 记录最新报告期、源文件SHA256、原图实际绘制的柱高/折线数值、原坐标系整合标志、各PNG哈希及独立披露期间核查。
4. `chart_period_qc.py`（G8-PERIOD）重新从原表计算，检查期间、实际/预测属性、图中数值、源文件和图像指纹。`chart_qc.py`和`gate_all.py`均强制调用；结果写 `reports/图表最新期审核.json`。旧图停留年报、只更新页脚日期、YTD冒充全年、E值替代实际或改数据未重建均不能通过。

## 期间语义

- 收入、净利、OCF、Capex和FCF原表为累计流量，季度柱由累计差分还原，Q1直接使用一季度累计。年度柱只用完整年原值。最新累计对上年同期的比较保留在证据包和正文表格，不能机械乘4/3充作实际全年。
- 原图当前年用浅色背景强调；刻度必须保留最新年份。增长折线仅保留橙色“年度同比”，用相邻完整财年原值计算；率类显示年度变动（百分点），资产类比较年末。取消全部季度同比、季度环比线（包括Q3），静态PNG、Plotly、标题、图例及图注同步。未完年度不画年度同比点，缺少上一自然年全年值不跨年替代；负基数、零基数或跨零不画失真增长率。季度同比、环比计算继续保留在证据包和正文比较表，不作为图上增长线。股价、估值带及明确标示的全年预测等用途折线保留。
- 季度毛利率/净利率按单季分子、分母计算；累计加权ROE不能用累计差分当单季ROE，明确“累计、非年化”，不作环比。BPS、负债率、现金净额按报告期末时点比较；率类变化用百分点。
- 图12全年E值以独立预测线明确标示，实际季度仍按所属年份分组；预测标签不能承担最新实际覆盖。
- 分部以最新实际披露为准。季度未给分部时，用最新中报并注明H1，不能把半年总额当全年增速。并列环形图只比较构成。
- 同行财务采用统一最新可比期。`fetch_peers_financials.py --period YYYY-MM-DD`可拉共同累计期；默认latest，不再默认筛年报。不同公司的最新季度进度不齐时取共同中报，披露理由；不可把旧年报静默混入。PE/PB的行情日期和财务指标期分别注明。
- DPS按归属财年，付款/除息日单列。当前财年未公告时写“未披露”，不得以0填充或将上一年度于本年支付的股利标为本年财年股利。
- 历史现金校验、敏感性和点时估值带保留本来的历史窗口/公告可得性；模型评估日注明最新期，不把事后财报回填历史行情。
- 不以日历年份强制生造尚未披露的财报。自动检测依据是原始三表的最新实际期；资料不足明确缺失并进入WARN/限制。

## 补充数据字段

`运营补充数据.json`的`segment.period_review`、`peers_period.period_review`、`dps.period_review`分别声明：

```json
{"checked_through":"最新三表报告期YYYY-MM-DD","period_end":"实际使用的独立披露期YYYY-MM-DD","basis":"FY/H1/YTD","source":"具体公告/CSV及页码","reason":"较早期仍是最新可比期的具体原因"}
```

`peers[]`每行还须有相同的`报告期`。DPS另有`current_fiscal_year_status`，如“FY2026方案未披露”，可补`latest_payment_date`。声明须反映实际图内数据，不是单纯贴最新日期。

缺失不补零。债务分项确经报表确认未发生但源接口留空，可在`input/图表期间配置.json`中指定`debt_absent_as_zero`（可选键short_loan/long_loan/bond/due_1y/lease），并写reason与来源；没有该声明则净债务衍生项保持unknown。

## 复验

G8-PERIOD从实际绘图artist保存年度同比线的年份、值、单位与条数；G8-RENDER重新构图读取实际折线，拒绝季度增长线、多余增长线、年度计算错误或未完年伪全年点。正例覆盖完整FY、相邻基期缺失、率类百分点及交互trace。

年度同比右轴刻度最多两位小数；小幅百分点变化用至少0.01的刻度间距及相应轴范围，避免直接四舍五入造成刻度重复或漏掉实际点。G8-RENDER检查实际刻度精度与唯一性。

### 自适应排版与柱上数字

- 全部标准图和五张体检图共用`chart_numbers.py`显示格式，金额标注按图轴亿元／万元；报告正文、表格、图注金额也只用亿元／万元，自适应单位必须逐格写明。`format_amount`接收人民币元，禁止把内部已缩放金额直接传入。切换显示不改原始数据与计算链。G8-PERIOD、G8-RENDER、G22核验共享精度声明与实际文字违规清单，模板门和HTML入口拦截旧金额单位。

- 每个已披露年度空心柱都标年度值（较大、加粗），每个已披露季度柱都标季度值（较小），不得只标最新季度。缺失值不标0。标签保持与本柱横向对齐，接近时垂直避让并显示必要的细引导线；根据标签实际边界扩展纵轴。
- 原图年度/季度柱值、最新值标题和交互悬浮数字最多2位小数，去掉末尾多余0，不用有效位数规则无限增加小数。单位同轴，0<值<0.01显示“<0.01”，-0.01<值<0显示“>-0.01”，真实零显示“0”。底注解释最小精度；原始值和计算链不得舍入。G8-PERIOD和G8-RENDER检查格式声明、实际标签和非零误标0。
- 先渲染测量图题、图例、每行主轴及右轴的标题/刻度/标签、底部注释的像素边界，再分配绘图区。图题→图例→绘图区→注释顺序明确；不得用多次固定rect/tight_layout重复预留顶部空间。图例列数、注释折行、左右边距、行间距及必要画布高度随实际文本和数据适配。
- 间距按相邻完整边界计算（包括标题和横轴刻度），不是只按坐标框计算。默认间隔10pt；门控要求图例到首行、相邻子图、末行到注释为3—26pt，禁止注释压在横轴或数据区。此范围是排版验收约束，实际位置由测量决定。
- `图表期间覆盖.json`保留布局测量结果、各指标年度/季度标注数量、标注文字与柱值一致性及残余碰撞。G8-PERIOD独立重算应有标注数并拒绝缺标、碰撞、过宽留白及负间距。保存图与重建审核使用同一布局入口。
- 全部标准图以及五张财报体检图共用测量布局。原生图的轴外脚注迁移到图级注释流；图例统一置于图上。等比例环形图按实际行边界压缩画布；长文本说明面板按文字高度顺序流排。保存PNG时显式保留已从tight_layout排除的图题、图例和脚注，避免导出裁掉内容。
- 环形图百分比须保持在对应扇区的配置半径（`pctdistance`）上。`fig_segment`移除饼图自动生成的空类别标签及被阈值隐藏的空百分比文本；`_auto_fix_layout`跳过不可见或空白文本，避免空标签扩展坐标范围后使百分比偏离扇区。不能通过扩大画布或移动百分比掩盖错误的数据锚点。
- `layout_native`合并图例前收集全部可见坐标轴的有效系列并去重，包括没有独立图例的右轴；移除旧图例后，成本、价格、供需等系列仍须齐全。图16价格线属于右轴时，也须出现在顶部图例。
- 各指标可从其首个可用年份展示，去除完全无数据的前导年份；中间缺失年份标注未披露，不为缩空白而补零。最新年始终保留。
- 散点公司名等offset points标注须在最终子图宽度确定后按像素边界收回轴内，不能仅检查transData文本。全部原生图记录并审核text_out_of_bounds；长公司名、窄画布及不同数量级数据均须验证。
- G8-RENDER重建所有标准图检查间距与文字碰撞；G22核验`本期财报体检_图表排版审核.json`的五图测量和PNG指纹。报告重渲染后逐张解码HTML内嵌PNG，对照当前PNG的SHA256，不能只刷新独立图片而继续交付内嵌旧图的HTML。

修改期间模块/构图/质量门后，运行`tests/test_chart_periods.py`及模板正、负回归。正例覆盖密集多年、负现金流、接近的每股数据、长注释和窄画布。负例至少覆盖：旧图停在上一年、右侧附图代替原图整合、累计冒充FY、预测冒充实际、原始数值变化、错误期末、分部只有日期声明却无本期数据、同行混期、漏柱值标注、标注碰撞、注释重叠和顶部留白过宽。实际交付再运行完整`gate_all.py`，人工查看收入、现金流（含负值）、分部、同行和分红图。

修改环形图或双轴布局时，另运行`python -m pytest tests/test_segment_label_layout.py -q`：覆盖三期与四期并列环形图，核查布局后百分比数据锚点及空标签清理，并检查右轴系列在统一图例中保留。该专项检查补充模板全图正、负回归；实际交付仍核对最终PNG和HTML内嵌图。
