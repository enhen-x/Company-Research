## 2. 穿透回报率模型 v3（核心公式与六大行业适配）

```text
1. 维持性现金底座（剥离扩张性 Capex 错杀，严抓假利润）：
   γ_maint = 0（金融）或 min(γ_total, γ_cap)（消费/互联网 0.80；制造/公用 0.90）
   Capex_maint = D&A × γ_maint
   OE_cash     = OCF_扣息 − Capex_maint   （银行 min(NP, AA_2y)；非银周期平滑）
   Cov_cash    = OE_cash / (NP_base × α)  （< 0.85 或分配偏差 ≥ 2pct → 现金含金量不合格！）

2. 留存再投资转化率 η ∈ [0, η_max] 与金融权益成本校准：
   - 互联网/消费/制造业（ROIC_eff ≥ R_req + 2%）：η = min(0.80, 0.80 × (ROIC_eff − R_req) / 15%)
   - 公用事业/基础设施（ROIC_eff ≥ R_req + 2%）：η = min(0.55, 0.55 × (ROIC_eff − R_req) / 12%)
   - 商业银行（Ke_fin = max(7.5%, R_req + 2%)）：η = min(0.25, 0.25 × max(0, ROE − Ke_fin) / 6.5%) × ρ_g
   - 非银金融（Ke_fin = max(6.5%, R_req + 2%)）：η = min(0.25, 0.25 × max(0, ROE_norm − Ke_fin) / 6.5%) × ρ_g
   - 金融增速兑现度 ρ_g（客观历史锚）：g_theo = ROE × (1 − p_dist)_+；从近5年利润序列计算近2年与全期复合增速，取偏审慎值 g_actual = min(g_4y, 0.6·g_2y + 0.4·g_4y)，得 ρ_g = clip(g_actual / g_theo, 0, 1)（序列 < 3 期默认 1.0）。实际负增长时 ρ_g = 0 强制退回纯分红收息；息差/增速承压时按实绩成比例折算，杜绝静态高 ROE 虚增留存价值。
   - 金融板块杠杆监管成本 + 破净折价保护 + 并购首年全期年化：当 ROE ≤ Ke_fin 或 ρ_g = 0 时 η=0；计算留存项分母取 max(市值, 归母净资产)，防止 PB<1 时按 1/PB 虚增；若当期发生重大吸收合并/扩表跃迁，按加权净资产口径将首年利润年化至全期并表基数。
   - 含金量不合格 / 未过门槛：η 强制归零（铁血防守，自动退化回纯分红收息公式）

3. 广义穿透回报率与安全边际：
   R_dist   = NP_base × α × p_dist / 市值         （分红 + 注销式回购）
   R_retain = NP_base × α × max(0, 1 − p_dist) × η / retain_denom  （非金融=市值；金融=max(市值, 净资产)）
   R_LT     = R_dist + R_retain
   R_cash   = OE_cash × p_dist / 市值 + OE_cash × max(0, 1 − p_dist) × η / retain_denom
   R_eff    = 含金量合格时取 R_LT（Δc≥2pct 取保守校准值）；含金量不足直接降级为现金分配口径 R_cash_dist
   R_req    = max(市场下限, Rf + 风险溢价)
   MoS      = R_eff − R_req + 周期修正
   P_buy    = 当前股价 × R_eff / R_req
   P_floor  = 当前股价 × R_req / R_eff （仅当 R_eff > R_req）
```

> **方法论边界提示**：阶段 2 的「未来 3 年 Capex 规划曲线、在建转固时间轴与分红率跃迁引擎（图19–图21）」属于**周期拐点与市场预期差**模块，另行在 `§4.2.1` 与 `§6.4.1`（或后续预期差总引擎）中独立列示，不直接混入本节基于已实现财务与资本效率的 `v3_look_through` 内生定价内核。

**历史自由现金结余（用于敏感性压力情景）**（近4~5年）：

```text
结余 = 真实现金收入（营业收入） + V1（其他经营现金流入）+ V5（投资现金流入）
       − V_deduct（相关扣除） − W（经营支出） − Y（总扣除）
```

- AA_2y = 最近2年结余均值；AA_all = 全部可得年份均值。
- 默认用 AA_2y；若最近年份异常（一次性损益、大额投融资），改用 AA_all 或剔除异常年并在报告说明。
- **经营性质异常规则（2026-08-15新增，2026-10-30修订）**：经营结构变化（渠道切换、业务重组、会计口径变更、大额减值等）致结余同比变动>±30%时复核AA；先判异常性质，再选AA_all、有依据地剔除异常年或保留AA_2y并解释。必须联动§4λ协议，保留全样本及异常年剔除诊断，仍不可靠时只作历史均值条件参考，不能强制置0；Warnings记录依据。
- FF = 账面现金 × (1 − 受限比例)；受限比例高（如>50%）必须进 Warnings。

## 2.1 成长校准轨（forward，2026-08-21 新增，小商品城批次校准）

**目的**：解决高成长标的"永远买不到"——保守轨 R* = C_trailing×k×M/市值 用 trailing C，
对净利 30%+ 增长的公司会把目标买入价压得远低于合理前瞻价值（小商品城：保守轨 6.83 元 vs
现价 12.48）。成长校准轨用**有证据支撑的前瞻盈利**重算穿透回报率，给出"成长验证买入区"。

**触发条件（缺一不启用）**：
1. C_fwd 有证据支撑：公司业绩指引/预告下沿、券商一致预期下沿、或自建模型（必须有驱动桥）；
2. C_fwd > C（trailing）；否则无意义；
3. 预测非曲棍球棒：C_fwd 同比增速 ≤ 历史 3 年最高增速，净利率 ≤ 自身历史峰值与可比龙头。

**口径**：
```text
R*_fwd = C_fwd × k_fwd × M_fwd / 市值
GG_fwd = AA_fwd × M_fwd / 市值（可选，现金校验）
Δc_fwd = R*_fwd − GG_fwd；≥2pct → 有效口径降级为 GG_fwd
KK_fwd = R*_fwd − II；目标买入价_fwd = 现价 × R*_fwd / II
成长验证买入区 = [保守轨目标买入价, 成长校准轨目标买入价]
```
参数默认：k_fwd = min(k, 0.85)（前瞻不确定性更高，折扣不放松）；M_fwd = M 保守锚，
分红率上行趋势 + 中期分红承诺时可按依据上调至近 3 年均值（须标注）。

**纪律（禁止越过保守轨）**：
1. **评级锚仍为保守轨 trailing**：KK ≤ 0 → 不建仓，评级不高于中性/观望；
2. 成长校准轨只提供"成长验证买入区"与升级参考，**不单独触发建仓**；
3. **升级条款**：仅当成长兑现被**实际数据**验证（如中报/季报归母 ≥ 预测阈值，且合同负债/现金流
   同步确认）后，才可用 C_fwd 更新主轨并重估评级——预测本身不构成升级；
4. 禁止把两轨目标价混用；报告必须并列披露两轨 R*/KK/目标买入价并标注口径；
5. 脚本：calc_penetration_return.py 提供 net_profit_C_fwd 即输出 growth_calib 块；
   build_penetration_input.py 用 --c-fwd/--m-fwd/--k-fwd/--aa-fwd/--c-fwd-source 生成。

> 案例（2026-08-21 小商品城）：C_fwd=55 亿（自建驱动桥+券商一致预期中值）、M_fwd=0.55（近3年均值，
> 分红率 40.8%→58.9%→65.2% 上行 + 2026 中期分红承诺 ≥25% H1 净利）、k_fwd=0.8 →
> R*_fwd≈3.54%、目标买入价_fwd≈12.0 元（保守轨 6.83 元 → 成长验证买入区 [6.83, 12.0] 元）；
> 若 M_fwd 维持保守锚 0.41 → R*_fwd≈2.64%、目标买入价_fwd≈8.95 元。KK_fwd（M_fwd=0.55）≈ -0.14pct 仍 <0
> → 评级维持中性/观望；中报 H1 归母 ≥16.5 亿 + 合同负债不降 → 触发升级重估。

## 3. 分配能力与分配意愿

**分配能力**（强/中/弱）：
- FCF 连续为正、筹资现金流持续为负（派息）、无再融资依赖 → 强。
- 现金上游障碍：母公司 vs 合并报表现金差异、重大子公司/少数股东、外汇管制；无重大障碍 → 强。

**分配意愿**（高/中/低）：
- 高：承诺分红比例或有量化分红政策。
- 中：无承诺，但持续多年稳定绝对分红额（如固定 DPS）。
- 低：分红波动大、下降或依赖借款/卖资产。
- 记录近3年支付率序列、均值、**最低档 M_min** 与标准差；近3年回购记录一并说明。M 锚定优先章程/公告承诺最低值，其次历史最低档（见 §1），均值仅交叉参考。

## 4. 收入敏感性（λ 与 k*）

```text
λ = Δ结余 / Δ收入          # 取多年平均；若符号不一致 → 可靠性警告
单年下滑 k：   结余(k) = AA − λ × 基准收入 × (1 − k)
逐年累积 k_n： 结余(k_n) = AA − λ × 基准收入 × (1 − k_n)，k_n = 0.9^n
GG(k) = 结余(k) × M / 市值
门槛价格(k) = 当前股价 × II / GG(k)
k* = 1 − (AA − II × 市值 / M) / (λ × 基准收入)     # GG(k*)=II 的解
```

- 情景表固定输出：单年 ×0.7 / ×0.8 / ×0.9 / ×1.0；逐年累积 ×0.9^1 / ×0.9^2 / ×0.9^3。
- k* < 0 时说明：线性外推在极端下滑区间失效，含义是安全边际极充裕，不得引用为精确临界点。
- 结论句式：即使在 X% 收入下滑情景下，现金口径 GG(k) 仍超门槛 Y pct，股价需下跌约 Z% 才使 GG(k) 降至门槛（主口径 R* 不随收入情景变动）。

**λ 失效处理协议（2026-10-30修订，华东医药校准；同时覆盖§2经营性质异常规则中的旧λ=0兜底条款）**：

1. **估计与展示**：列示近 4~5 年逐年 Δ结余/Δ收入 与多年平均 λ；逐年符号不一致（正负混出）即输出 `λ 可靠性存疑` 警告（外推可信度 ⑤ 按"符号矛盾→低"计）。
2. **触发降级（任一）**：① 逐年符号不一致；② \|λ\| 异常大（>1.5 需逐项解释，2026-08 贵州茅台 λ=3.99 即属此类）；③ 最近年份结余受结构性/一次性因素扭曲（渠道切换、大额投融资、资产处置、会计口径变更）。
3. **处理流程**：有披露依据才剔除异常年重估，同时保留全样本及剔除诊断。新输入设置`lambda_policy=historical_mean_reference`，计算器重新计算配对历史逐段斜率的算术均值，覆盖遗留的`lambda=0`。正负混合、异常段或单段主导只降低可靠性，不将估计改为0；不得挑选正斜率或为画斜线任意定参数。无有效区间不得启用参考模式，生成器仅在此时保留旧兼容路径并披露无有效估计。
4. **k* 失效情形**：λ=0时分母为0；λ可靠性低时无论是否非零，计算器均输出null。可靠性足够但k*不在(0,1)内时仅作定性解释，并结合λ符号和基准GG判断，不能声称有精确收入下滑安全空间。
5. **敏感性表参考标注**：注明「历史均值λ、可靠性低、仅条件参考」，解释样本和不稳定原因，不作为盈利预测或建仓依据。现金情景买价=当前价×GG(k)/II，不替代主R_eff买价。`legacy_zero`仅用于旧输入兼容；真实均值恰为0时如实保留，不能声称真实经营弹性为0。

**图11数据链（强制）**：`reports/穿透回报率_输出.json`是敏感性数值唯一机器来源。无运营指定时，从`single_year[].k`、`single_year[].gg`及`II`自动出图；`script_cash_surplus`须逐点一致，`g_grid`/`capex_g`须与网格G及oe_yield一致，人工模式偏差须WARN并披露依据。参考模式须在标题、系列或图注明示历史均值λ、可靠性与条件演算含义。真实均值为0或旧兼容模式按结果保留平线并解释，不得为画斜线编造弹性，也不能把零均值解释为真实经营弹性为零。

默认出图时，有限非零λ的横轴为收入倍数；低可靠性由计算器输出驱动标题与图注，缺运营输入也须保留。零λ或λ未提供时使用压力情景系数并解释平线。门控识别零值须匹配完整数值，不能把`λ=0.0117`等非零小数误判为`λ=0`，也不能用非零λ的文字声明为平线免责。

> 历史案例（2026-08-15贵州茅台）：2025渠道切换致结余-33%，λ=3.9926符号不一致，k*=1.014无临界意义。旧版曾要求λ=0兜底，当前按2026-10-30修订协议执行，旧批次不自动回写。

## 5. 外推可信度（5维）

| # | 维度 | 高 | 中 | 低 |
|---|---|---|---|---|
| ① | 收入波动率（5年CV） | <10% | 10~20% | >20% |
| ② | 利润调整幅度 | <5% | 5~15% | >15% |
| ③ | \|HH\| 账面-现金偏差 | <1pct | 1~2pct | ≥2pct |
| ④ | 经营模式变化 | 无重大变化 | 有变化但可解释 | 重大变化 |
| ⑤ | λ 可靠性 | 无警告 | 一项警告 | 符号矛盾/多项警告 |

外推可信度 = 计数汇总：高≥3 → 高；中≥3（或高低混合）→ 中；低≥3 → 低。
输出格式：`外推可信度：中（2高 + 3中 + 0低）`。

## 7. 股价位置与目标买入价

- 用10年周线（约460+数据点）算历史分位。
- `目标买入价 = 当前股价 × R_eff / II`：**有效穿透回报率 R_eff（默认主口径 R*，现金校验失败时降级为 GG）恰好等于门槛 II 时的股价**，即最高可买价（买入上限）；当前价低于它 → 无需等待回调；股价涨破它 → R_eff 跌破门槛 → 触发卖出/换仓评估。
- `门槛价格 = 当前股价 × II / R_eff`（= 现价² ÷ 目标买入价）：**深度低估/下行保护参考价**——股价跌至此价时，穿透回报率升至 R_eff²/II（= 门槛的 R_eff/II 倍），远高于门槛。⚠️ 它不是"R_eff=II 时的股价"（那是目标买入价）；仅当 R_eff > II（达标）时有效（此时低于现价）；当 R_eff ≤ II 时门槛价格 ≥ 现价，失去参考意义，只以目标买入价为等待参考。
- 输出：10年最高/最低价、当前分位、目标买入价及其分位。

## 8. 业绩下滑敏感性表

表1（逐年累积，每年−10%）与表2（单年不同幅度）每行输出：情景 / 可支配现金结余 / 现金口径 GG(k) / vs门槛 / 情景目标买入价 / vs当前股价。（校验维度；主口径 R* 不随收入情景变动）

```text
vs门槛 = GG(k) − II
情景目标买入价(k) = 当前股价 × GG(k) / II = (AA(k)×M + O) / (II×总股本)   # 情景 k 下 GG=II 的股价（情景最高可买价，敏感性表主列）
门槛价格(k) = 当前股价 × II / GG(k)   # 情景 k 下行保护参考（跌至此价 GG(k) 升至 GG(k)²/II）
vs当前股价 = 情景目标买入价(k) / 当前股价 − 1    # 负数 → 该情景下需股价下跌该幅度（或基本面修复）才达门槛
```

## 9. 绝对估值与基准价

```text
EV = 市值 + 有息负债 − 广义净现金（货币资金 + 交易性金融资产）
EV/EBITDA
扣除现金PE = (市值 − 广义净现金) / AA        # 穿透口径
FCF收益率 = FCF / 市值
净负债/EBITDA = (有息负债 − 广义净现金) / EBITDA
商誉/总资产
股息率 = DPS / 当前股价
```

基准价三锚（算术平均 → 综合基准价）：

```text
① 净流动资产/股 = (货币资金 + 交易性金融资产 − 有息负债) / 总股本
② 每股净资产 = 归母权益 / 总股本
③ 10年最低收盘价（周线）
溢价率 = 当前股价 / 综合基准价 − 1
```

溢价高时必须解释来源（如现金安全垫+高分红 vs 成长溢价），不得单看百分比下结论。

## 10. 仓位决策

```text
单股仓位上限 = min( ① 商业模式上限, ② KK 安全边际档位, ③ 行业集中度余量 ) × ④ 市场水位系数
实际仓位     = min( 单股仓位上限, ⑤ 价格档位折算 )
```

**① 商业模式上限（硬顶，先于 KK 判定）**——按视频教程口径：

| 商业模式类型 | 单股上限 | 示例 |
|---|---|---|
| 尾部风险/法律边缘（造假前科、监管重罚、重大诉讼） | ≤5% | 法律边缘类 |
| 强周期（纸/油/煤/航运/地产链，价格不可预测） | ≤10% | 理文造纸 |
| 稳定公用/顶级模式（低竞争垄断、稳定现金牛、隐形冠军） | 20~30%（保守默认20%） | 长实、腾讯、百胜、福寿园、凌霄泵业 |
| 一般公司 | 按最接近类别**从严归类**，报告写明归类依据 | — |

**② KK 安全边际档位（候选，非最终仓位；KK = R_eff − II，R_eff 默认主口径 R*，现金校验失败时降级为 GG）**：

| KK | 可信度 | 陷阱风险 | 候选档位 |
|---|---|---|---|
| ≥1.5pct | 中 | 低 | 70% |
| 1.0~1.5pct | 中 | 低 | 50% |
| <1.0pct 或 可信度低 或 陷阱中/高 | 相应降档 | 相应降档 | ≤30%（或观望） |

**③ 行业集中度**：单一行业持仓合计 ≤30~40%；已达上限 → 新标的只建观察仓。

**④ 市场水位（弹性差理论，定性三档）**：低水位（上证≤3000 / 恒指≤16000）→ 组合放大弹性，个股上限取高档；中水位 → 正常；高水位（上证>3500 / 恒指>24000）→ 组合收缩、倾向低波高息，个股上限 ×0.7。

**⑤ 价格档位（价格决定实际推多少）**：现价 < 目标买入价×0.8 → 可推满上限；现价 ∈ [0.8, 1.0)×目标买入价 → 按上限一半建仓；现价 ≥ 目标买入价 → 不买或只建观察仓。

报告必须写出完整推导链，例如：`KK≥1.5pct+可信度中+陷阱低 → 候选70% → 商业模式上限30%（顶级稳定）→ 行业余量充足 → 价格可推满 → 水位中性 → 目标仓位30%`。未满足更高档时说明降档原因。若 KK 未达门槛（R_eff≤II），不建仓，输出观望/卖出。
