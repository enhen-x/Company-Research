# 行业与公司分析框架

本文档涵盖行业分析方法和公司分类体系。内容提炼自《华尔街证券分析》(胡克)和《证券分析》(格雷厄姆&多德)。

## 一、自上而下分析法

证券分析采用自上而下的分析路径：

```
宏观经济 → 资本市场 → 行业分析 → 公司分析 → 财务分析 → 财务预测 → 估值 → 投资建议
```

每一层级的分析为下一层级提供背景和假设基础。

## 二、行业分析

### 2.1 行业分类
- **按产品/服务分类**：制造业、服务业、金融业、科技业等
- **按周期性分类**：防御型、周期型、成长型
- **按生命周期分类**：初创期、成长期、成熟期、衰退期

### 2.2 行业分析要素

#### 2.2.1 外部因素
- **宏观经济**：GDP增速、利率、通胀、汇率
- **人口趋势**：老龄化、城市化、消费习惯变化
- **政府政策**：监管、税收、产业政策、贸易政策
- **技术变革**：颠覆性技术、技术替代风险
- **社会趋势**：消费偏好、环保意识

#### 2.2.2 需求分析
- 市场规模和增长率
- 客户群体特征和购买力
- 需求驱动因素
- 替代品威胁
- 季节性和周期性模式

#### 2.2.3 供给分析
- 行业产能利用率
- 进入壁垒（资本需求、技术门槛、品牌、牌照）
- 退出壁垒
- 供应链结构
- 原材料成本趋势

#### 2.2.4 获利能力与定价
- 行业利润率水平及趋势
- 定价权归属（买方/卖方）
- 成本结构（固定vs变动比例）
- 规模经济效应
- 行业集中度和竞争格局

#### 2.2.5 国际竞争
- 进出口影响
- 全球产能分布
- 汇率影响
- 贸易壁垒

### 2.3 行业分析关键问题清单
1. 行业处于生命周期的哪个阶段？
2. 行业增长率高于还是低于GDP增速？
3. 行业的进入壁垒是什么？
4. 行业的定价权掌握在谁手中？
5. 行业是否受技术替代威胁？
6. 行业利润率是在扩张还是收缩？
7. 行业是否受政府监管重大影响？
8. 国际竞争如何影响国内企业？

## 三、公司分析

### 3.1 系统分析方法

#### 3.1.1 概述与业务描述
- 公司历史和发展沿革
- 主要产品和服务线
- 收入构成（按产品/地区/客户）
- 核心竞争优势

#### 3.1.2 产品和市场
- 各产品线的市场规模和份额
- 客户集中度
- 产品生命周期位置
- 研发管线和新产品

#### 3.1.3 生产和分销
- 生产设施和产能
- 供应链管理
- 分销渠道
- 成本结构

#### 3.1.4 竞争分析
- 主要竞争对手及市场份额
- 差异化因素（品牌、技术、成本、网络效应）
- 竞争优势的可持续性
- 波特五力模型应用

#### 3.1.5 其他主题
- 管理层背景和激励机制
- 公司战略和近期举措
- 法律诉讼和监管风险
- ESG（环境、社会、治理）因素

### 3.2 竞争优势评估框架

评估公司竞争优势时关注：
1. **品牌价值**：品牌认知度、客户忠诚度
2. **成本优势**：规模经济、低成本资源、工艺效率
3. **网络效应**：用户基数带来的价值递增
4. **转换成本**：客户更换供应商的成本
5. **监管壁垒**：牌照、专利、准入限制
6. **技术领先**：研发能力、专利组合

## 四、公司分类体系

华尔街将公司按特征分为6类。完成财务分析后，将研究公司归类。

### 4.1 成熟型公司

**特征**：
- 销售收入和利润温和稳定增长
- 财务比率年际差异小
- 收购影响易于区分
- 利润率保持稳定

**分析要点**：
- 关注基础业务收入趋势（剔除收购）
- 预测相对可靠，趋势可延伸
- 适合使用时间序列预测法

**案例特征**：消费品制造商、公用事业、大型食品公司

### 4.2 成长型公司

**定义**：每年12%~15%或更高的销售及利润增速。

**三个子类**：

| 类型 | 特征 | 案例 |
|------|------|------|
| 经典成长型 | 提供前所未有的新产品/新技术 | 太阳能、iPod、GPS |
| 市场份额成长型 | 在成熟行业中夺取竞争对手份额 | 诺基亚（2005-2007） |
| 市场整合型 | 通过不断收购同行扩大份额 | 小镇报刊连锁 |

**分析要点**：
- 利润增长道路可能崎岖
- 业务消耗现金（设备、应收、存货投资）
- 常需股权或债权融资支持扩张
- 市场整合型需验证：基础业务稳固、收购价格合理、协同效应真实

### 4.3 周期型公司

**特征**：
- 利润随商业周期涨落
- 高固定成本 → 高经营杠杆
- 兴盛伴随衰退，周期重复

**分析要点**：
- **不用当年利润**作为预测起点（阶段是暂时的）
- 计算整个周期的**平均年盈利能力**（含1~2个坏年份和3~4个好年份）
- 评估经营杠杆比率：利润变化相对销售收入变化的程度
- 仔细评估**债务偿还能力**（能否在整个周期偿还债务）
- 预测中应包含至少1~2年的下行周期
- 现金储备是否足以度过衰退期

**关键指标**：
- 周期内的平均EBIT、EBITDA、ROE
- 利息覆盖倍数（在周期低谷的水平）
- 现金储备 / 月度燃烧率

### 4.4 衰退型公司

**特征**：
- 销售额和利润率持续下降
- 行业面临结构性萎缩（如报纸、马鞭制造商）

**分析要点**：
- 区分周期性下降与永久性衰退
- 分析现金流量表和资产负债表判断可持续能力
- 很少有投资者愿意投资

### 4.5 转型公司

**特征**：
- 曾经盈利的公司到了转折点
- 销售增速疲软，利润率落后于竞争对手
- 管理层出台重振计划

**分析要点**：
- 集中分析历史现金流量和杠杆比率
- 判断是否有时间和资源推行重振计划
- 评估底层资产价值（如废物管理公司的垃圾填埋地、客户合同）
- 接受转型失败的可能性

### 4.6 先锋型公司

**特征**：
- 销售收入很少，几乎没有盈利
- 现金流为负
- 历史财务分析几乎无用

**分析要点**：
- 计算燃烧率：月现金流出 = (运营费用 + 研发费用 + 资本开支 - 经营性现金流入) / 12
- 用手头现金 / 燃烧率 = 无外部融资下的存续月数
- 估值完全凭预测，与历史几乎无关
- 强调定性分析：技术可行性、市场接受度、管理层执行力

## 五、公司分类决策流程

```
是否有稳定的销售和利润？
├─ 是 → 增长率是否高于12-15%？
│       ├─ 是 → 成长型公司（进一步区分三个子类）
│       └─ 否 → 成熟型公司
└─ 否 → 利润是否随周期涨落？
        ├─ 是 → 周期型公司
        └─ 否 → 是否曾盈利但正在下滑？
                ├─ 是 → 转型公司（有重振计划）或衰退型公司（结构性萎缩）
                └─ 否 → 先锋型公司（初创/高研发）
```

## 六、自上而下与自下而上方法对比

### 自上而下
- 从宏观经济出发 → 行业 → 个股
- 适合系统性选股，关注宏观和行业趋势
- 大多数卖方研究报告采用此方法

### 自下而上
- 直接从公司基本面出发
- 适合发现被市场忽视的价值
- 格雷厄姆式的"寻找便宜货"方法

**推荐**：以自上而下为主线，辅以自下而上的验证。先确认行业趋势有利，再深入研究公司基本面。
