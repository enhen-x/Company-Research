## 附：龟龟投资法各值定义（报告口径说明）

> 本附录是报告全篇统一口径：以下所有变量、公式、价格锚与仓位规则，报告引用时必须与此一致，禁止混用其他含义。金额统一为百万元，每股统一为元，比率统一用 % 展示。

### 附1｜利润与现金还原（C / D / G / H / OE / M / O / AA / FF）

| 符号 | 名称 | 公式 / 口径 | 含义与使用说明 |
|------|------|------------|---------------|
| C | 归母净利润 | 近1年 GAAP 归母净利（扣非仅作对比） | 账面利润起点 |
| D | 折旧与摊销 | 近1年 | 非现金费用，计算时加回 |
| G | 维持性 Capex 系数 | 轻资产 0.7~1.0；中等 ≈1.0~1.3；重资产 1.2~1.8；需给依据（近3年 Capex/D&A）；**扩产→收缩切换期强制 G 网格**（0.5/0.7/0.9，脚本 g_grid 输出） | 维持现有盈利所需资本开支占折旧摊销的比例；保守方向取大值；网格行禁止手写/手抄 |
| H | 维持性 Capex | H = D × G | 从现金流中扣除的维持性资本开支 |
| OE | Owner Earnings（所有者盈余） | OE = C + D − H | 维持现有规模后可自由分配的经营现金流；G 网格口径（GG=OE×M/市值）与之挂钩 |
| M | 支付率（保守锚） | 法2 = 分配现金/归母净利；**顺序取**：章程/公告承诺最低值 → 管理层承诺 → 历史稳定（近3年极差<5pct）→ 无规律取近3年最低档 M_min；均值仅交叉参考；法1 = DPS/EPS 仅校验 | 公司把利润分给股东的比例（分红+回购）；两法偏差 >5pct 时排除法1 |
| O | 注销型回购年均 | 近3年注销回购金额均值 | 提高每股价值，可并入可分配现金 |
| AA | 真实可支配现金结余 | 近2年均值 AA_2y（默认）；近5年均值 AA_all 对比 | 穿透现金口径：经营/投资现金流入扣除维持性支出后的“真实利润”，现金校验口径 GG 的分子 |
| FF | 可自由支配现金 | 账面现金 × (1 − 受限比例) | 受限比例 >50% 必须进 Warnings |

### 附2｜穿透回报率与门槛（k / R* / R / GG / Δc / R_eff / HH / II / JJ / KK）

| 符号 | 名称 | 公式 / 口径 | 含义与使用说明 |
|------|------|------------|---------------|
| k | 利润折扣系数 | 可预测性：高→0.9 / 中→0.8（默认）/ 低→0.7；保守方向取小值 | 主口径核心参数：对账面利润打折，剔除利润含金量不足的风险 |
| R* | 主穿透回报率（主估值输入） | R* = C × k × M / 市值 | **默认最终估值输入**；含义：现价买入后，按打折净利润 × 最低支付率每年可获得的回报率 |
| R | 账面穿透回报率（交叉校验） | R = C × M / 市值 | 用账面利润不打折粗算，交叉校验用 |
| GG | 现金结余校验口径 | GG = AA × M / 市值 | 用真实可支配现金测算，**校验 R\* 是否有真钱支撑**；含义：现价买入后按现金口径可获得的回报率 |
| Δc | 现金校验偏差 | Δc = R* − GG | ≥2pct → 现金验证失败，有效口径降级为 GG |
| R_eff | 有效穿透回报率 | 默认 R*；Δc≥2pct 时 = GG | **最终估值输入**：安全边际、目标买入价、门槛价格、仓位全部基于 R_eff |
| HH | 账面-现金偏差 | HH = R − GG | 正常 <2pct；≥2pct → 专项调查 |
| II | 门槛（最低要求回报率） | A股：max(3.5%, Rf+2%)；港股：max(5%, Rf+3%)；美股：max(4%, Rf+2%) | Rf = 当地10年期国债收益率；低于此回报不值得承担股权风险 |
| JJ | 安全边际 | JJ = R_eff − II | 有效回报超过门槛的部分 |
| KK | 周期性修正安全边际 | 弱周期 = JJ；强周期按周期位置：底部 → R_eff−(II−1pct)，顶部 → R_eff−(II+2pct) | 仓位决策的最终输入 |

### 附3｜收入敏感性（λ / k*）

| 符号 | 名称 | 公式 / 口径 | 含义与使用说明 |
|------|------|------------|---------------|
| λ | 经营杠杆 | λ = Δ结余 / Δ收入（多年平均） | 收入每变动 1 元，真实可支配现金变动 λ 元；逐年符号不一致 → 可靠性警告 |
| k | 收入下滑幅度 | 单年 ×0.7 / ×0.8 / ×0.9 / ×1.0；逐年累积 ×0.9^n | 敏感性表情景 |
| GG(k) | 情景现金口径回报率 | 结余(k) = AA − λ×基准收入×(1−k)；GG(k) = 结余(k)×M/市值 | 下滑情景下的现金校验回报（校验维度）；主口径 R* 不随收入情景变动 |
| k* | 临界收入倍数 | k* = 1 − (AA − II×市值/M) / (λ×基准收入) | GG(k*)=II 的临界点；k*<0 → 线性外推失效，只作定性解读（安全边际极充裕） |

### 附4｜价格锚（目标买入价 / 门槛价格 / 情景目标买入价）

| 术语 | 公式 | 定义与含义 | 使用说明 |
|------|------|-----------|---------|
| 目标买入价（龟龟买入价） | 当前股价 × R_eff / II | **R_eff 恰好等于门槛 II 时的股价**（= (R_eff×市值)/(II×总股本)），即最高可买价（买入上限） | 现价 < 买入价 → 可买入（已达标）；现价 > 买入价 → 等待回调或基本面改善；股价涨破买入价 → R_eff 跌破门槛 → 触发卖出/换仓评估 |
| 门槛价格（龟龟门槛价） | 当前股价 × II / R_eff（= 现价² ÷ 目标买入价） | **深度低估/下行保护参考价**：股价跌至此价时，有效回报率升至 R_eff²/II（= 门槛的 R_eff/II 倍），远高于门槛 | ⚠️ 它不是“R_eff=II 的股价”（那是目标买入价）；仅当 R_eff > II 时有效（此时低于现价，衡量下行保护厚度）；R_eff ≤ II 时 ≥ 现价，失去参考意义 |
| 情景目标买入价(k) | (AA(k)×M + O) / (II×总股本) = 当前股价 × GG(k) / II | 收入下滑情景 k 下 GG=II 的股价（情景最高可买价） | 业绩下滑敏感性表主列；vs当前股价 负值 → 该情景下需股价下跌该幅度（或基本面修复）才达门槛 |
| 门槛价格(k) | 当前股价 × II / GG(k) | 情景 k 下的下行保护参考价 | 跌至此价 GG(k) 升至 GG(k)²/II |

**三者关系**：目标买入价 × 门槛价格 = 当前股价²；情景目标买入价(k) 随 AA(k) 下降而下降（基本面恶化 → 可买价下移）。

**口径分离纪律**：券商 12 个月目标价（盈利×倍数外推）与龟龟价格（现金流穿透回报口径）含义不同，报告必须并列标注、禁止混用。

### 附5｜仓位与决策纪律

```text
单股仓位上限 = min(① 商业模式上限, ② KK 候选档, ③ 行业集中度余量) × ④ 市场水位系数
实际仓位     = min(单股仓位上限, ⑤ 价格档位折算)
```

| # | 变量 | 规则 |
|---|------|------|
| ① | 商业模式上限（硬顶） | 尾部风险/法律边缘 ≤5%；强周期（纸/油/煤/航运/地产链）≤10%；稳定公用/顶级模式 20~30%（保守默认20%）；一般公司从严归类并写明依据 |
| ② | KK 候选档 | KK ≥1.5pct+可信度中+陷阱低 → 70%；KK 1.0~1.5pct+可信度中+陷阱低 → 50%；KK <1.0pct 或可信度低或陷阱中/高 → ≤30%（或观望） |
| ③ | 行业集中度 | 单一行业合计 ≤30~40%；已达上限 → 只建观察仓 |
| ④ | 市场水位（弹性差） | 低水位（上证≤3000/恒指≤16000）→ 取高档；高水位（上证>3500/恒指>24000）→ 上限×0.7、倾向低波高息；中水位正常 |
| ⑤ | 价格档位 | 现价 < 目标买入价×0.8 → 推满上限；0.8~1.0× → 上限一半；≥ 目标买入价 → 不买/观察 |
| — | 门槛纪律 | R_eff ≤ II（未达门槛）→ 不建仓，观望/卖出 |

报告必须写出完整推导链，例如：`KK≥1.5pct+可信度中+陷阱低 → 候选70% → 商业模式上限30% → 行业余量充足 → 价格可推满 → 水位中性 → 目标仓位30%`；缺环必须降档或说明。
