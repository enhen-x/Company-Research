# 财务分析与预测指南

本文档涵盖财务报表分析、会计数据局限性、管理层操纵识别和财务预测方法。内容提炼自《华尔街证券分析》(胡克)和《证券分析》(格雷厄姆&多德)。

## 一、财务报表分析框架

### 1.1 分析步骤
1. 获取至少5年（周期型公司至少一个完整周期）的财务数据
2. 计算关键财务比率和趋势
3. 与同行业可比公司对比
4. 识别异常和警示信号
5. 必要时调整会计数据以反映经济现实

### 1.2 关键财务比率

#### 盈利能力
| 指标 | 公式 | 说明 |
|------|------|------|
| 毛利率 | 毛利润 / 销售收入 | 产品定价权和成本控制 |
| 营业利润率 | 营业利润 / 销售收入 | 核心经营效率 |
| 净利率 | 净利润 / 销售收入 | 最终盈利能力 |
| ROE | 净利润 / 股东权益 | 股东回报 |
| ROA | 净利润 / 总资产 | 资产使用效率 |
| ROIC | NOPAT / 投入资本 | 资本配置效率 |

#### 偿债能力
| 指标 | 公式 | 说明 |
|------|------|------|
| 资产负债率 | 总负债 / 总资产 | 杠杆水平 |
| 利息保障倍数 | EBIT / 利息费用 | 偿债能力 |
| 流动比率 | 流动资产 / 流动负债 | 短期偿债能力 |
| 速动比率 | (流动资产-存货) / 流动负债 | 严格短期偿债能力 |

#### 运营效率
| 指标 | 公式 | 说明 |
|------|------|------|
| 存货周转率 | 销售成本 / 平均存货 | 存货管理效率 |
| 应收账款周转率 | 销售收入 / 平均应收 | 收款效率 |
| 资产周转率 | 销售收入 / 总资产 | 资产使用效率 |

#### 增长指标
- 销售收入增长率
- 净利润增长率
- 每股收益（EPS）增长率
- 同店销售增长率（零售业）

### 1.3 杜邦分析
ROE = 净利率 × 资产周转率 × 权益乘数

分解ROE以判断回报来源：运营效率（净利率）、资产效率（周转率）或杠杆（权益乘数）。

## 二、会计数据的局限性

### 2.1 核心认知
> "财务报表是事实、会计惯例、个人判断的结合体，深受惯例和判断的影响。"

财务报表的精确性外表掩盖了真相：许多会计分录依赖管理层和审计师的职业判断，没有实际交易背景。

### 2.2 六大会计问题

#### 国际性问题
1. **金融公司及金融产品的会计**：并购产生的商誉和无形资产摊销影响盈利可比性
2. **国际会计准则差异**：美国GAAP与国际IFRS的区别，新兴市场当地准则可能差异更大
3. **收入确认**：完工百分比法、毛收入vs净收入等

#### 特定公司问题
4. **管理层自主判断**：折旧年限、坏账准备、存货计价方法的选择
5. **管理层vs分析师**：管理层有动机夸大业绩，审计师客观性受损
6. **潜在欺诈**：伪造发票、隐瞒负债、虚构销售

### 2.3 管理层夸大财务状况的手段

#### 利润表操纵
| 科目 | 常见手法 |
|------|---------|
| 销售 | 货发即确认收入、向信誉不佳客户销售、宽松付款条件、集中到季度末确认、低估售后保证、滥用完工百分比、互换交易、毛收入vs净收入、伪造发票 |
| 销售成本 | 使用FIFO而非LIFO（通胀下虚增利润） |
| 人工成本 | 修改养老金/医疗保障精算假设（提高假设回报率降低成本） |
| 折旧 | 延长折旧年限 |
| 无形资产摊销 | 延长摊销期限 |
| 研发费用 | 将研发成本资本化而非费用化 |
| 一次性冲销 | 夸大一次性冲销以降低未来费用、避免重编历史报表 |

#### 资产负债表操纵
| 科目 | 常见手法 |
|------|---------|
| 应收账款 | 低估坏账准备 |
| 存货 | 不及时减记过时存货 |
| 固定资产 | 低估折旧使账面价值虚高 |
| 长期投资 | 不及时减值 |
| 商誉 | 将收购溢价全归入商誉（不摊销）而非可辨认无形资产 |
| 负债 | 隐藏表外负债、经营租赁不入账 |
| 养老金 | 使用乐观精算假设 |

### 2.4 分析师的应对策略
1. **看透数字背后的真相**：不盲信管理层和审计报告
2. **检查会计政策一贯性**：期间变更会计方法会削弱可比性
3. **与同行业对比**：行业内的显著差异需调查
4. **研究财务报表附注**：附注是不可或缺的信息来源
5. **调整财务报表**：必要时用自己的假设重新计算
6. **关注现金流量表**：银行里的现金难以造假
7. **识别巨额冲销**：频繁"一次性"支出是警示信号

## 三、财务预测方法

### 3.1 预测的阶梯（自上而下）

```
宏观经济假设 → 行业增速假设 → 公司市场份额假设 → 销售收入预测
→ 毛利率假设 → 营业利润预测 → 利息费用 → 税前利润
→ 所得税 → 净利润 → 股份数 → EPS
```

### 3.2 销售收入预测三大方法

#### 时间序列法
- **适用**：食品、电力、医疗等基础产业；稳定防御型公司
- **方法**：移动平均、指数平滑、趋势线
- **假设**：未来与过去相似
- **弱点**：无法预测转折点和商业周期

#### 因果关系法
- **适用**：稳定/衰退阶段企业、周期/防御型行业、成长后期企业
- **方法**：建立销售收入与独立变量（GDP、人口、新屋开工等）的回归关系
- **优势**：能反映外部驱动因素变化

#### 定性分析法
- **适用**：初创企业、新产品/新服务、缺乏历史数据的公司
- **方法**：专家观点、市场调查研究、历史类比
- **注意**：即使有稳定销售的公司也建议辅以定性分析

### 3.3 财务预测七步骤

1. **完成历史财务分析**：理解过去的业绩模式
2. **匹配销售收入预测方法**：根据公司类型选择合适方法
3. **设定自上而下假设**：经济、行业、市场的合理假设
4. **预测至EBIT**：从销售收入到息税前利润
5. **估计融资结构**：未来债务vs股权融资（必须现实——多数公司只能发行垃圾债或股票）
6. **完成至EPS**：利息费用 → 税前利润 → 净利润 → EPS
7. **现实检查**：回头审视数字是否合理，咨询独立第三方

### 3.4 三种情景分析

| 情景 | 假设 | 用途 |
|------|------|------|
| 上行情景（乐观） | 无衰退、产品推介平稳、适度竞争 | 上行空间评估 |
| 基准情景（最佳猜测） | 温和增长、正常竞争环境 | 核心估值依据 |
| 下行情景（悲观） | 衰退、价格战、转折点 | 下行风险检查 |

- 成熟公司：基准预测EBIT在±10%区间
- 长期预测（7~10年）：应包含至少一次经济衰退
- 周期型公司：基础情景须含1~2年下行周期

### 3.5 常见预测错误

1. **曲棍球棒现象**：为证明投资建议正确性而突然提高未来盈利预测
2. **天真假设债务融资**：多数公司无法轻易发行投资级债券
3. **过度乐观**：投资行业的职业病，卖方分析师长期预测系统性偏乐观
4. **忽视周期**：周期型公司预测中不包含下行年份
5. **后视镜驾驶**：完全依赖历史延伸，不预判转折点
6. **管理层影响**：将预测呈给管理层后被劝阻做出保守假设

### 3.6 每股收益（EPS）影响因素

**利润增长 ≠ EPS增长**。需关注三种财务策略：

#### 发行新股支持增长
- 净利润增长但股本扩张更快 → EPS下降
- 分析要点：未来是否需要继续大量发行新股？

#### 股票回购提升EPS
- 减少发行在外股数 → EPS上升
- 有效性取决于：现金机会成本、负债成本、股价、税率、市盈率

#### 提高杠杆率加速EPS增长
- 用债务替代股权融资 → 避免稀释但增加风险
- 晴天（乐观）下EPS增速更快，雨天（悲观）下偿债压力大

**核心原则**：正确的财务分析应揭示这些影响EPS的财务策略。

## 四、现金流量表分析

### 4.1 重要性
> "银行里的现金难以造假。"

由于会计准则的灵活性，净利润可以用不同方式列示，但现金流更难操纵。分析师研究现金流量表以辨别现金流入是否与利润一致。

### 4.2 分析要点
1. **经营性现金流 vs 净利润**：持续偏离是警示信号
2. **资本支出**：维持性vs增长性资本支出
3. **自由现金流**：经营性现金流 - 资本支出
4. **融资活动**：债务变化、股票发行/回购、股利支付
5. **现金余额变化**：是否在消耗现金储备

### 4.3 常见问题模式
- "公司账面显示利润，但付款存在问题，现金越来越少"
- 原因可能：资本投资增加、存货积压、应收账款膨胀

## 五、信息来源

### 5.1 公司层面
- 年度报告和季度报告
- 财务报表附注
- 股东大会委托书
- SEC/交易所公告
- 公司投资者关系部门

### 5.2 行业层面
- 行业协会数据
- 咨询公司报告
- 政府出版物
- 贸易期刊

### 5.3 市场层面
- 商业媒体
- 证券公司研究报告
- 信用评级机构
- 独立专家服务
- 数据服务商（Bloomberg、Wind、同花顺等）

### 5.4 格雷厄姆的完整性标准
一份完整的损益账户应包含：
1. 销售收入
2. 净收入
3. 折旧（和损耗）
4. 利息支出
5. 非营业收入（明细）
6. 所得税
7. 股息分配
8. 盈余调整（明细）

> "隐瞒销售收入或折旧费用使得人们根本无法有效地对财务报表进行分析。"
