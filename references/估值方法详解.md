# 估值方法详解

本文档阐述主要估值方法。先按 [研究专题](research-topics.md) §2选择行业经济模型、主方法与验证锚，再读取本文件的适用计算章节；不是要求每份报告运行全部方法。行业矩阵、指引/订单、驱动预测及反方证据规则集中维护于专题文件，不另设报告结构。

报告保留§6.1市场估值与双锚，但双锚含义为行业适用的主方法与验证锚；PE/PB仅适用时使用。有限寿命生产矿山、银行股权剩余收益、保险内含价值、REIT NAV/AFFO等不能由普通企业永续DCF代替。脚本尚不支持或输入不足时明确标记不可估值/数据不足。

## 一、内在价值法（现金流量折现法 DCF）

### 1.1 原理
公司的内在价值是其未来现金股息（或自由现金流）的折现现值。DCF从理论上最完善，但在实践中应用受限。

### 1.2 稳定增长模型（戈登模型）

**公式**：P = D₁ / (k - g)

- P = 内在价值
- D₁ = 下一年度现金股息
- k = 股东要求的年化回报率（折现率）
- g = 预期股息年化增长率

**适用条件**：稳定资本结构、稳定增长率的公司。

### 1.3 两阶段增长模型

**适用条件**：增长率不稳定的公司（周期性、初创期、有特殊股息历史）。

**方法**：预测未来5~10年股息，此后假设稳定增长。前10年用各年增长率g₁到g₁₀，第11年起用稳定增长率g₁₁。

### 1.4 DCF估值四步流程

**第1步：预测**
- 准备未来5~10年预测，含利润表、资产负债表、资金来源与使用
- 从中预测股东可支配的自由现金流

**第2步：终值**
- 方法A（DCF法）：假设预测期结束后进入稳定增长，用戈登模型计算
- 方法B（相对价值法）：用可比公司市盈率乘以预测期末净利润
- 两种方法可分配权重（如各50%）

**第3步：折现率**
- 用适当折现率折现所有未来现金流和终值
- 注意：终值常占净现值的75%以上，需格外小心

**第4步：每股价值**
- 股权净现值 / 流通普通股股数
- 考虑期权、可转债、权证等稀释因素

### 1.5 DCF的优缺点

**优点**：
- 理论上最有依据，符合常理
- 债权人和债券定价常用
- 符合"向前看"的投资逻辑

**缺点**：
- 严重依赖5~10年预测，超过1年就不精确
- 折现率难达成共识
- k或g的1%微变导致巨大估值差异
- 终值常超估值一半，削弱现金流预测重要性

### 1.6 安全边际应用
计算出的每股价值设±15%安全边际。低于下限买入，高于上限卖出。

## 二、折现率选择

### 2.1 资本资产定价模型（CAPM）

**公式**：k = Rf + β × (Rm - Rf)

- k = 股票要求回报率
- Rf = 无风险利率（如10年期国债）
- β = 贝塔系数（股票相对市场的波动性）
- Rm = 股票市场预期收益率
- (Rm - Rf) = 市场溢价

**贝塔系数解读**：
- β = 1.0：与市场同步
- β = 1.5：波动是市场的1.5倍
- β < 1.0：比市场波动小

**CAPM的局限**：
- 贝塔仅衡量历史敏感度，预测未来效果有限
- 2008年崩盘表明投资人要求回报率高于CAPM计算值

### 2.2 积层法（Build-up Method）

**适用**：没有可比贝塔数据的新上市公司或非上市公司。

**公式**：k = Rf + 权益风险溢价 + 行业风险溢价 + 规模风险溢价 + 公司特定风险溢价

- 权益风险溢价：投资股票而非政府债券的溢价
- 行业风险溢价：正或负，取决于行业历史表现
- 规模风险溢价：小企业历史回报率高于大企业
- 公司特定风险溢价：单一客户主导、高杠杆等为正；无杠杆、强专利保护为负

### 2.3 投机性公司的折现率
对业绩记录少、前景不确定的投机性公司，折现率应接近风险投资要求（26%~75%），按发展阶段递减。

## 三、相对价值法

### 3.1 原理
将目标股票的估值参数与同行业可比公司比较。若估值参数远低于同业且无合理解释，则值得买入。

### 3.2 常用估值比率

| 比率 | 公式 | 适用场景 |
|------|------|---------|
| 市盈率（P/E） | 股价 / 每股收益 | 盈利稳定的公司 |
| EV/EBITDA | 企业价值 / 息税折旧摊销前利润 | 资本密集型、跨国公司 |
| EV/销售额 | 企业价值 / 销售收入 | 亏损公司、高增长公司 |
| 市净率（P/B） | 股价 / 每股净资产 | 金融类、困境公司 |

**企业价值（EV）计算**：
EV = 市值 + 总债务 + 优先股 + 少数股东权益 - 现金及等价物

### 3.3 相对价值分析步骤

1. **选择可比公司**：同行业、相似规模、相似业务模式
2. **构建比较表**：列出各家公司的关键财务指标和估值比率
3. **历史业绩排名**：按行业相关指标为每家公司打分
4. **加权评分**：对增速指标给予更高权重（如40%），其他指标各20%
5. **对比排名与估值**：排名高但估值低的公司可能是投资机会
6. **调查偏离原因**：排名与估值不匹配时，深挖背后解释

### 3.4 房地产类比
相对价值法类似房地产评估——通过对比周边可比房产的近期售价确定标的房产价值。每个可比交易旁边总结与标的相比更好或更差的属性。

### 3.5 相对价值法的优缺点

**优点**：
- 可比上市公司价格公开透明
- 计算过程有实质内容，基于审计后财务数据
- 避免了DCF中对k和g的争议

**缺点**：
- 上市公司极少有真正相似的可比对象
- 无法判断整个行业是否被高估或低估
- 注重历史经营成果比较，"看后视镜驾车"是危险策略
- 相对价值投资者虽损失小于行业，但仍可能蒙受绝对损失

### 3.6 高市盈率风险
买入50倍P/E股票，若5年后以20倍P/E卖出（仍高于平均），EPS须翻4倍才能实现市场回报率。

### 3.7 PE 失真规则与 PB 适用性

- **失真机制**：TTM 净利≤0 或趋近于零时，PE 无定义或数值极端（如数百倍），此时 PE 历史分位被“盈利分母刚修复”污染，不能直接作为估值便宜的证据。
- **处理规则**：
  1. 盈利正常期才计算 PE 分位；亏损/微利期在图上标注“PE 无定义”，不静默留白；
  2. PB仅在净资产有效且有经济解释力时作为验证锚；PB也受盈利能力、资产质量和减值影响，不是与周期无关的固定底。PE无效时保留可比较的PB观测，不能用填充值构造连续序列；
  3. 亏损公司逐项核对替代方法适用性：EBITDA为正且维持投入可解释时才讨论EV/EBITDA；负净资产不可用常规PB；收入倍数需受盈利率和现金转化约束。图13/14不适用时保留图号并使用既有豁免。

### 3.8 分阶段估值带（行业生命周期 × 本阶段分位）

- **原则**：先以行业经济模型和资产/现金流性质决定方法，再按生命周期判断正常化盈利、终值和资本需求。PE/PEG、PB、FCF/分红等阶段切换仅是适用业务的候选，不是全行业统一规则。不能将不同口径或不同阶段混为全历史分位。
- **操作**：
  1. 按基本面证据划分阶段（量增速、盈利能力、政策、格局），图上色块标注；
  2. 对方法适用、口径一致且样本足够的阶段计算该指标分位；PE/PB不足时说明，不虚构分位；
  3. 评价以“当前阶段内百分位”为主，全历史分位为辅；
  4. 给出阶段末值（当前值）在本阶段内的分位，用于判断该阶段末的估值位置。

## 四、并购价值法

### 4.1 原理
公开交易股票的市价不应低于它对有经验的第三方收购者所值价值的70%~75%。

### 4.2 分析步骤
1. 收集行业内的收购价格和对应乘数
2. 将收购乘数应用于目标公司的财务数据
3. 估计目标公司作为收购对象的吸引力
4. 计算合理的收购价值区间
5. 将收购价值的70%~75%作为股价下限参考

### 4.3 优缺点

**优点**：
- 收购价格是公开数据
- 可辅以私下交易价格

**缺点**：
- 可比并购数据比上市公司可比数据更少
- 私下交易信息不充分
- 收购价格受市场情绪影响，可能与未来基本面相悖

## 五、杠杆收购法（LBO）

### 5.1 原理
从PE收购视角估值。PE基金通过大量举债收购目标公司，用目标公司现金流偿还债务，数年后出售获利。

### 5.2 LBO估值要素
- **可获得的举债额度**：基于EBITDA的倍数
- **利息成本**：取决于信用评级和市场条件
- **还款计划**：现金流分配
- **退出乘数**：出售时的EV/EBITDA
- **持有期**：通常3~7年

### 5.3 LBO目标公司特征
- 低技术含量行业
- 持续稳定的盈利记录
- 近乎无负债的资产负债表
- 强劲的自由现金流
- 可变现资产（用于偿还债务）

### 5.4 优缺点

**优点**：
- 假设可由PE参与者验证
- PE有长期LBO历史，增加可信度

**缺点**：
- 很多公司缺乏LBO潜质
- 战略收购方通常出价更高，LBO常作为底价参考

## 六、边缘公司的估值调整

### 6.1 三类问题公司

**第1类：一次性盈余减少**
- 有良好历史业绩，近期出现暂时性亏损
- 处理方式：剔除非经常性损益，使用标准化数据

**第2类：业绩不稳定**
- 包括起伏型、周期型、持续亏损公司
- 处理方式：
  - 平均3~5年业绩平滑化
  - 对估值乘数打折扣（如从10倍EV/销售额降至6倍）
  - 周期型公司：使用整个周期平均盈利

**第3类：自然资源类**
- 拥有未开采的石油、矿产、林地
- 处理方式：计算未来开采成本与预期收入

### 6.2 亏损公司估值比率
当P/E无经济解释力时，按行业规则和输入有效性筛选以下候选；不是自动替代：
- **EV/EBITDA**：最常用，适用于有线电视、移动通信、石油、酒店、博彩
- **市净率（P/B）**：适用于困境企业和金融类公司
- **EV/销售额**：适用于有扭亏潜力、正引进新产品的高科技公司
- **每股经营数据**：如每用户收入、每床位收入等行业特定指标

## 七、分部加总法（Sum of Parts）

### 7.1 适用场景
多元化经营的企业集团，各业务板块性质差异大。

### 7.2 步骤
1. 按未来3–5年主要价值贡献和经济模型拆分重要业务；订单不能额外作为已预测现金流之外的资产重复计价
2. 对各重要业务采用适用方法及其生命周期假设；明确企业价值/股权价值、净债、少数股东和集团费用，防止同一项重复调整。现有SOTP脚本不支持的行业方法不得改名成PE或EV/EBITDA后套入
3. 加总各业务部门价值
4. 加上非经营性资产（如超额房地产、投资）
5. 减去非经营性负债（如养老金缺口、诉讼风险）
6. 考虑税收影响（资产分拆vs现金出售的税负差异）
7. 可能需扣除集团折价（conglomerate discount）

### 7.3 注意事项
- 分部估值可能揭开被掩盖的真实价值
- 税收因素对分拆决策影响重大
- 市场对多元化企业通常施加"集团折价"

## 八、估值结果呈现：目标价分情况展示与安全边际

### 8.1 目标价分情况展示

- **情景矩阵**：悲观/基准/乐观 × 概率 × 2027E（或目标年度）EPS/倍数 × 目标价，标注对现价上下行空间与触发条件。
- **范围三层表述**：
  1. 概率加权目标价（情景目标价按概率加权）；
  2. 多方法合成仅在方法适用且权重有依据时进行，揭示共同盈利/资本成本假设；不得照搬固定权重或把缺失方法分配零权重后假称全方法验证；
  3. 方法交叉区间由本行业适用模型、关键输入和情景给出，注明未解决的反方证据与数据边界；不机械以PB分位构造支撑。

### 8.2 安全边际（格雷厄姆框架，量化）

1. **价值折价**：现价相对本行业适用价值区间的折价；概率加权、相对中枢与DCF若共享关键假设，不计为多个独立安全边际；
2. **资产保护（适用时）**：核实净资产质量、可回收性、资本约束与优先索取，不能仅凭未来BPS增加推定股价下限；
3. **风险不对称**：基准上行 vs 悲观下行，计算盈亏比（上行空间/下行空间）；
4. **边界声明**：明确不覆盖的尾部情景（如量价双杀）与触发跟踪条件；安全边际不能替代月度基本面跟踪。
