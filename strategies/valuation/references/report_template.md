# 估值模块报告模板兼容说明

估值模块不再维护独立主报告模板。所有“独立估值分析”如果形成对外主报告，必须使用技能唯一主模板：

`../../../references/report-template.md`

该模板固定十部分章节：投资摘要、宏观与行业分析、公司分析、财务分析、盈利预测、估值分析、投资建议与目标价、催化剂与跟踪、风险与反证条件、附录。

估值模块的计算结果主要映射到：

- 第 1 章：估值结论、关键数字、数据限制；
- 第 6 章：公司分类、WACC、定性调整、估值方法、敏感性、交叉验证、反向估值；
- 第 7 章：三情景目标价、概率加权目标价、双轨评级、目标买入价、门槛价格和仓位；
- 第 9 章：估值假设风险、尾部压力测试和反证条件；
- 第 10 章：数据来源、方法公式、图表清单、复验记录和免责声明。

第 2、3、4、5、8 章仍必须保留，并填入该章节要求的事实、数据依据和 `**本节结论**`；第 4 章必须包含 `§4.1` 至 `§4.4`，其中 `§4.3` 必须完整回答九个关键问题。缺少数据时保留章节并标注“数据不可用/不适用”及影响。

估值计算中间结果保存在 `valuation_computed.md`，不替代主报告。成稿后必须运行：

```bash
python scripts/report_template_qc.py --report reports/<公司>_<代码>_分析报告.md
```

本文件仅为旧路径兼容说明，不得复制为独立报告结构。
