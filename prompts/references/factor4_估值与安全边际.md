# 因子4：估值与安全边际 — 详细计算步骤

> 本文件为 Phase 3 执行器的参考文件。Agent 3 在执行因子4时按需加载本文件。金额单位统一为百万元。

**指令**：以有效穿透回报率 R_eff（默认主口径 R* = C×k×M/市值；现金验证失败 Δc≥2pct 时降级为 GG）为锚，判断安全边际并排查价值陷阱。仅对通过因子1-3的标的执行。

## 步骤1：门槛计算

```
Rf = [输入值]%（来源：data_pack §14 无风险利率）

港股门槛 = max(5%, Rf + 3%) = max(5%, [计算值]%) = [II]%
A股门槛 = max(3.5%, Rf + 2%) = max(3.5%, [计算值]%) = [II]%
美股门槛 = max(4%, Rf + 2%) = max(4%, [计算值]%) = [II]%（Rf = 美国十年期国债收益率）

有效穿透回报率 [R_eff]% vs 门槛 [II]%
  R_eff ≥ II → 通过，进入步骤2
  R_eff < II → 不达标
    若疑似成长性支出占总扣除额 > 30% → 标注"建议细化假设重新测算"
    否则 → 排除
```

## 步骤2：价值陷阱排查

逐项检查（仅调用前序因子结论，不做新分析）：

| 序号 | 陷阱特征 | 数据来源 | 判断标准 | 结果 |
|------|---------|---------|---------|------|
| 1 | 现金流趋势性恶化 | 因子3结余序列 | 连续≥2年下降且降幅>15% | [存在/不存在] |
| 2 | 护城河正在收窄 | 因子1B模块三 | 非技术层侵蚀判定为"负面"，或技术层被颠覆（竞争对手算法/数据优势逆转）；若为复合护城河飞轮，单层收窄但另一层稳固的可降级为"中"而非直接触发 | [存在/不存在] |
| 3 | 行业结构性衰退 | 因子1B模块四 | 终端需求不可逆萎缩（非周期性波动） | [存在/不存在] |
| 4 | 分配意愿存疑 | 因子3分配意愿 | 判定为"弱" | [存在/不存在] |
| 5 | 管理层损害价值 | 因子1B模块六 | 判定为"损害价值"或"观察期" | [存在/不存在] |

```
存在项数 = [N]
  N = 0 → 价值陷阱风险：低
  N = 1 → 价值陷阱风险：中，标注风险点
  N ≥ 2 → 价值陷阱风险：高
    若 R_eff > II × 1.5 → 保留（回报率足够覆盖风险）
    否则 → 排除
```

## 步骤3：安全边际与仓位

```
安全边际 = 有效穿透回报率 − 门槛 = [值] 个百分点（JJ = R_eff − II）

周期性修正（仅强周期企业）：
  周期底部 → 门槛下调1pct → 修正安全边际 = R_eff - (II - 1%)
  周期顶部 → 门槛上调2pct → 修正安全边际 = R_eff - (II + 2%)
  周期中段或非周期 → 不调整

修正后安全边际 = [值] 个百分点（KK）
```

### 仓位决策（前置上限 → 候选档 → 最终仓位）

```text
单股仓位上限 = min(① 商业模式上限, ② KK 候选档, ③ 行业集中度余量) × ④ 市场水位系数
实际仓位     = min(单股仓位上限, ⑤ 价格档位折算)
```

**① 商业模式上限（硬顶，先于 KK 判定）**：

| 商业模式类型 | 上限 | 示例 |
|------|------|------|
| 尾部风险/法律边缘（造假前科、监管重罚、重大诉讼） | ≤5% | — |
| 强周期（纸/油/煤/航运/地产链，价格不可预测） | ≤10% | 理文造纸 |
| 稳定公用/顶级模式（低竞争垄断、稳定现金牛、隐形冠军） | 20~30%（保守默认20%） | 长实、腾讯、百胜、福寿园、凌霄泵业 |
| 一般公司 | 按最接近类别从严归类，写明依据 | — |

**② KK 候选档位矩阵（安全边际驱动，非最终仓位）**：

| 条件 | 候选档位 |
|------|---------|
| 安全边际 ≥ 1.5pct + 外推可信度高 + 陷阱风险低 | 标准仓位 |
| 安全边际 ≥ 1.5pct + 外推可信度高 + 陷阱风险中 | 70% |
| 安全边际 ≥ 1.5pct + 外推可信度中 + 陷阱风险低 | 70% |
| 安全边际 0.5-1.5pct + 外推可信度高 + 陷阱风险低 | 50% |
| 安全边际 0.5-1.5pct + 外推可信度中 + 陷阱风险低 | 观察仓位（30%） |
| 安全边际 0-0.5pct | 观察或等待 |
| 安全边际 < 0 | 不建仓 |
| 外推可信度低 | 观察或不建仓 |
| 陷阱风险高且回报率 < 门槛×1.5 | 排除 |

**③ 行业集中度**：单一行业持仓合计 ≤30~40%；已达上限 → 新标的只建观察仓。
**④ 市场水位（弹性差理论）**：低水位（上证≤3000 / 恒指≤16000）→ 组合放大弹性、个股取高档；中水位 → 正常；高水位（上证>3500 / 恒指>24000）→ 组合收缩、倾向低波高息、个股上限 ×0.7。
**⑤ 价格档位（价格决定实际推多少）**：现价 < 目标买入价×0.8 → 推满上限；现价 ∈ [0.8, 1.0)×目标买入价 → 按上限一半建仓；现价 ≥ 目标买入价 → 不买或只建观察仓。

最终推导链：`KK档 → min(候选, 商业模式上限, 行业余量) × 水位系数 → 价格折算 → 目标仓位`；缺环必须降档或说明。


## 步骤4：股价位置与买入触发价评估

**目的**：评估当前股价在历史长周期中的位置，并由门槛反推目标买入价，判断买入触发概率。

### Step 4-1：目标买入价反推

```
目标买入价 = 当前市值 × (R_eff / II) / 总股本

  其中：
  - R_eff = 有效穿透回报率（默认主口径 R*；Δc≥2pct 降级为 GG）
  - II = 门槛值
  - 逻辑：若以目标买入价购入，有效穿透回报率恰好等于门槛II%

  若 R_eff ≥ II → 目标买入价 ≥ 当前股价（已达标，目标价为上限参考）
  若 R_eff < II → 目标买入价 < 当前股价（需等待回调）
```

### Step 4-2：历史价格数据获取

> **§17.6 预计算加速**：若 data_pack_market §17.6 存在，直接引用当前股价分位、关键分位价格（10%/25%/50%/75%/90%）和数据点数。可跳过手动分位计算。若 §17.6 缺失，从 §11 原始数据手动计算。

```
数据要求：
  - 获取过去10年（或上市以来，取较短者）的周线收盘价
  - 数据来源：data_pack_market §11/附录A（来自 Tushare weekly 或 yfinance）
  - 若数据不足10年，使用全部可用数据并标注实际覆盖区间

输出变量：
  [NN] = 数据点数量
  [OO] = 10年最低价（及日期）
  [PP] = 10年最高价（及日期）
```

### Step 4-3：分位计算与买入触发评估

```
当前股价历史分位 = (当前股价低于历史价格的数据点数) / NN × 100%

目标买入价历史分位 = (目标买入价低于历史价格的数据点数) / NN × 100%

买入触发评估：
  目标买入价分位 ≤ 10%  → 触发概率极低（仅历史极端底部可触及）
  目标买入价分位 10-25% → 触发概率低（需显著回调）
  目标买入价分位 25-50% → 触发概率中等（历史中位数以下）
  目标买入价分位 50-75% → 触发概率较高（股价常处于此区间）
  目标买入价分位 > 75%  → 当前已在目标价附近或以下

综合判断：
  若 R_eff ≥ II 且当前股价分位 < 75% → "已达标，当前价位合理"
  若 R_eff ≥ II 且当前股价分位 ≥ 75% → "已达标，但股价偏高位，可等待回调以提升安全边际"
  若 R_eff < II 且目标买入价分位 ≤ 10% → "需大幅回调至历史极端低位，实际触发概率极低"
  若 R_eff < II 且目标买入价分位 10-50% → "需等待回调，历史上有一定概率触及"
  若 R_eff < II 且目标买入价分位 > 50% → "目标价在历史常见区间，等待机会"
```

### Step 4-4：业绩下滑敏感性分析

> **§17.9 预计算加速**：若 data_pack_market §17.9 存在，直接引用两张表格的预计算值。若 §17.9 缺失，从因子3结论手动计算。

**核心变量**：真实可支配现金结余 AA（来自因子3步骤7），而非归母净利润。本表为现金结余口径 GG(k)（校验维度）；主口径 R* 不随收入情景变动。

```
公式（现金口径 GG(k)，校验维度）：
  现金口径回报率_scenario = (AA_new × M% + O) / 当前市值
  情景目标买入价 = (AA_new × M% + O) / (II% × 总股本)   # 该情景下使 GG(k)=II 的股价（情景最高可买价）

  其中：
  - AA_new = AA × 下滑因子
  - M = 支付率锚定值（来自 §17.2）
  - O = 年均回购金额（来自 §17.2，默认0）
  - II = 门槛值（来自 §17.2 / 步骤1）
```

**表1：逐年累积下滑（每年-10%，1-3年）**

| 情景 | 真实可支配现金结余 | 现金口径 GG(k) | vs 门槛 | 情景目标买入价 | vs当前股价 |
|------|------------------|-----------|---------|---------|----------|
| 基准 | AA | GG% | ±X pct | [值] | ±X% |
| 下滑1年 (×0.9) | AA×0.9 | ... | ... | ... | ... |
| 下滑2年 (×0.9²) | AA×0.81 | ... | ... | ... | ... |
| 下滑3年 (×0.9³) | AA×0.729 | ... | ... | ... | ... |

**表2：单年不同下滑幅度**

| 下滑幅度 | 真实可支配现金结余 | 现金口径 GG(k) | 情景目标买入价 | vs当前股价 |
|---------|------------------|-----------|---------|----------|
| -10% | AA×0.9 | ... | ... | ... |
| -20% | AA×0.8 | ... | ... | ... |
| -30% | AA×0.7 | ... | ... | ... |

```
解读（现金口径校验维度）：
  若下滑3年后现金口径 GG(k) 仍 ≥ II → 现金韧性较厚
  若下滑1年后即 < II → 现金韧性薄，需密切关注业绩趋势
  情景目标买入价 = 在该情景下，使现金口径恰好等于门槛II%的股价（= 当前股价×GG(k)/II）
  vs当前股价 = (情景目标买入价 - 当前股价) / 当前股价
    正值 → 当前价格低于情景目标买入价，已有安全垫
    负值 → 需要股价下跌该幅度（或基本面修复）才达门槛
  注：下行保护参考"门槛价格"基于有效口径（= 当前股价×II/R_eff，跌至此价有效回报率升至 R_eff²/II），仅在 R_eff>II 时有意义；情景表内现金口径门槛价格 = 当前股价×II/GG(k)，勿与情景目标买入价混淆
```

## 步骤5：绝对估值与"买入就是胜利"基准价

> **§17.8 预计算加速**：若 data_pack_market §17.8 存在，直接引用估值指标和基准价。
> 若 §17.8 缺失，从 §1-§5 原始数据手动计算。

### Step 5-1：估值指标确认

从 §17.8 读取并评估：
- EV/EBITDA < 8x → 估值偏低信号
- 扣除现金PE < 10x → 排除现金后盈利能力强
- FCF收益率 > 8% → 自由现金流产出丰厚
- 净负债/EBITDA < 2x → 财务风险可控
- 商誉/总资产 → 商誉减值风险分级：
  - \> 30% → ⚠️ 商誉集中风险，步骤2价值陷阱排查中额外标注，仓位上限降至 50%
  - 20-30% → ⚠️ 商誉减值风险，标注并与因子1B模块六（资本配置记录）交叉验证商誉来源（收购标的质量、是否已减值）
  - < 20% → 正常处理

### Step 5-2：基准价与溢价评估

从 §17.8 读取综合基准价和溢价率：
- 溢价率 ≤ 0% → "买入就是胜利"区间，多重安全边际交汇
- 溢价率 0-30% → 接近基准，安全边际充足
- 溢价率 30-80% → 合理溢价，需确认成长性支撑
- 溢价率 > 80% → 较高溢价，需强劲增长预期

结合步骤3的安全边际判断，给出综合评估。
